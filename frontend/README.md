# Frontend

The frontend is a Next.js App Router app that talks to the Rails API running on port `3000`.

## Quick start

```bash
cp .env.example .env.local
npm install
npm run dev
```

The app runs on `http://localhost:3001`.

For a production-style validation build:

```bash
npm run build
```
